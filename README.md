# LogicBox Lab - Landing Page

Landing page for [logicboxlab.com](https://logicboxlab.com) that redirects visitors to the Cyprus Tax Calculator.

## Features

- 🎨 Modern, animated landing page
- ⚡ Auto-redirect to Cyprus Tax Calculator after 3 seconds
- 📱 Fully responsive design
- 🔒 Google AdSense integration ready

## Deployment

This site is designed to be deployed on GitHub Pages, Netlify, or Vercel.

### GitHub Pages
1. Push to `main` branch
2. Enable GitHub Pages in repository settings
3. Set custom domain to `logicboxlab.com`
